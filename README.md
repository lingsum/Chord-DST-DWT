# Chord-DST-DWT
Project: The Performance of  DST-Wavelet Feature Extraction for Guitar Chord Recognition.
Software: Python.
Dataset: The dataset used in this project is primary data. It consists of two-second audio signals recorded in WAV format, covering seven guitar chords (C, D, E, F, G, A, and B). The recordings were captured at a sampling frequency of 5 kHz, in accordance with Shannon’s sampling theorem, which requires the sampling rate to be at least twice the highest frequency component of the signal. Visual inspection of the signal spectrum revealed the highest frequency component to be 392 Hz, corresponding to the G4 note, a subset of the G chord. All recordings were performed on a Yamaha CPX-500-II guitar, using a single variation of chord playing. The sessions were conducted in a quiet environment to minimize noise, and single-channel recordings were employed since spatial information was not required for this task.
